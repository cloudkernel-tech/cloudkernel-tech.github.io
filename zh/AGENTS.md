## About the Repo
- The repo contains files to build a website for Cloudkernel Technologies Co. Ltd

## Dev environment tips
- The build environment has been properlly setup in current computer. Be sure to deactivate conda environment before build.
- Use command 'bundle exec jekyll build' to build the website, and files will be generated under the _site folder.
- Use command 'bundle exec jekyll serve' to serve the website for testing.
